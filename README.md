# New-Anki — Medical Image Enrichment

أداة لإضافة صور طبية مرخّصة إلى بطاقات Anki الموجودة، مع الحفاظ على المجموعة الأصلية.

## ما أُنجز
- سكربت يقرأ APKG قائمًا ويضيف صورًا للبطاقات المحددة صراحةً في ملف الموضوعات.
- البحث عن الصور يتم عبر Wikimedia Commons.
- فلترة أولية للتراخيص: CC0 وPublic Domain وCC BY وCC BY-SA، مع رفض NC وND.
- إنشاء ملف APKG جديد وتقرير JSON بالمصادر وحالة كل بطاقة.
- GitHub Actions لتشغيل العملية يدويًا دون رفع ملف APKG إلى المستودع.

## طريقة الاستخدام
1. انسخ `topics.example.json` إلى ملف باسم `topics.json` داخل المستودع، وعدّل قيم `match` و`query` لتطابق بطاقاتك.
2. ضع ملف APKG على خدمة توفر رابط تنزيل مباشر. لا ترفع ملف APKG إلى هذا المستودع.
3. افتح تبويب **Actions** ثم اختر **Enrich Anki deck with medical images** ثم **Run workflow**.
4. أدخل رابط التنزيل المباشر في خانة `apkg_url`، واترك `topics_path` على `topics.json`، ثم شغّل.
5. افتح نتيجة التشغيل الناجح، ونزّل Artifact باسم `illustrated-anki-deck`.

## بنية topics.json
كل عنصر يحتاج:
- `match`: نص فريد موجود في حقول البطاقة.
- `query`: عبارة بحث تصف الصورة المطلوبة.
- `field`: اختياري؛ اسم حقل Anki الذي ستضاف إليه الصورة. يفضّل عادةً `Back` حتى لا تظهر الصورة قبل محاولة الاسترجاع.

لن يضيف السكربت صورة إذا لم يجد تطابقًا واحدًا بالضبط.

## مهم
- استخدم نسخة احتياطية دائمًا؛ الناتج ملف مستقل ولا يستبدل الأصل.
- راجع الصور علميًا قبل اعتمادها؛ البحث الآلي لا يضمن أن الصورة هي الأفضل تعليميًا.
- تحقق من متطلبات كل ترخيص ونسب العمل لصاحبه.
- رابط APKG يجب أن يكون تنزيلًا مباشرًا متاحًا لـ GitHub Actions؛ روابط Drive التي تعرض صفحة معاينة أو تتطلب تسجيل الدخول قد لا تعمل.
